# GitHub Repository Setup

## After creating your repository on GitHub:

1. **Repository URL:** https://github.com/alexanderodwumaah-blip/portfolio
2. **Run these commands in your portfolio folder:**

```bash
git remote add origin https://github.com/alexanderodwumaah-blip/portfolio.git
git branch -M main
git push -u origin main
```

## Then you can deploy using:
- **Vercel:** Import from GitHub for automatic deployments
- **GitHub Pages:** Enable in repo settings → Pages
- **Netlify:** Connect to GitHub for continuous deployment

Your code is already committed locally, so you just need to push it to GitHub!
