How the admin works

Projects and Digital Work

Add, edit or remove entries. Changes are saved to your browser's local storage and exported as a JSON snippet you paste into script.js or index.html.

Skills

Add or rename skill categories and update the descriptions shown in the Capabilities section of your portfolio.

CV Upload

Generate the exact filename and path instructions for placing your CV PDF in the cv/ folder so the download buttons work correctly.

Deploying changes

After making changes, use the generated code snippets and run firebase deploy --only hosting from your portfolio folder to push live.
